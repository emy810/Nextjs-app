# Next.js Gallery App

A simple and clean gallery application built with **Next.js**, featuring a styled Home page and two gallery pages for Cats 🐱 and Dogs 🐶. The project uses the App Router and CSS Modules for a modern, organized structure.

## 🌐 Live Demo

https://nextjs-app-beryl-one.vercel.app/

## ✨ Features

- Next.js App Router (`src/app`)
- Styled Home page with gradient background
- Cats and Dogs gallery pages
- Captions under each image
- Responsive layout using CSS Modules
- Deployed on Vercel
